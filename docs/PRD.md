# TaskFlow — 个人任务管理系统 项目需求文档（PRD）

> 版本：v1.0  
> 最后更新：2026-07-07  
> 技术栈：React + TypeScript + Vite ｜ Node.js + Express + TypeScript ｜ SQLite ｜ Tailwind CSS

---

## 1. 项目概述

### 1.1 项目背景

在日常工作和学习中，人们面临大量待办事项，缺乏一个轻量、直观的工具来管理任务优先级和进度。市面上的任务管理工具（如 Jira、Trello）功能强大但过于复杂，对于个人用户来说学习成本较高。

TaskFlow 旨在提供一款 **简洁、高效、零门槛** 的个人任务管理工具，帮助用户专注于"做事"本身。

### 1.2 项目目标

| 目标 | 描述 |
|------|------|
| **功能完整** | 覆盖任务 CRUD、状态流转、分类、优先级、截止日期、数据统计等核心能力 |
| **易于使用** | 界面直观，新用户无需培训即可上手 |
| **全栈实战** | 前后端分离架构，帮助开发者掌握全栈开发流程 |
| **可扩展** | 模块化设计，便于后续添加用户认证、数据导出等功能 |

### 1.3 核心价值

- **对个人用户**：一个轻量级的任务管理工具，清晰掌握每日待办。
- **对开发者**：一个完整的全栈项目实践，涵盖数据库设计、API 开发、前端交互。

## 2. 用户角色与使用场景

### 2.1 目标用户

| 角色 | 描述 |
|------|------|
| **个人用户（主要）** | 学生、自由职业者、职场人士，需要管理日常待办事项 |
| **开发者（次要）** | 学习全栈开发的编程新手，通过本项目学习实战技能 |

> 本系统为 **单用户个人工具**，不涉及多用户协作场景。v1.0 无需用户注册/登录。

### 2.2 典型使用场景

| 场景编号 | 场景名称 | 描述 |
|----------|----------|------|
| S-01 | 快速记录任务 | 用户突然想到一件事，打开系统快速创建任务，设置截止日期后保存 |
| S-02 | 规划每日工作 | 用户早上打开系统，查看所有待办任务，按优先级排序，规划今日工作 |
| S-03 | 更新任务进度 | 用户开始处理某任务时，将状态从"待办"改为"进行中" |
| S-04 | 完成任务归档 | 用户完成一项任务后，标记为"已完成"，获得成就感 |
| S-05 | 查看完成情况 | 用户周末回顾本周，通过数据看板查看完成了多少任务 |
| S-06 | 分类管理任务 | 用户将任务按"工作"、"学习"、"生活"分类，方便筛选查看 |
| S-07 | 处理过期任务 | 用户查看已过期但未完成的任务，决定是加急处理还是重新规划日期 |

## 3. 功能需求

### 3.1 功能总览

```
TaskFlow
├── 任务管理（核心）
│   ├── F-01 创建任务
│   ├── F-02 查看任务列表
│   ├── F-03 编辑任务
│   ├── F-04 删除任务
│   └── F-05 任务状态流转
├── 属性管理
│   ├── F-06 任务分类管理
│   └── F-07 优先级设置
├── 提醒机制
│   └── F-08 截止日期提醒（视觉提示）
└── 数据看板
    └── F-09 统计面板
```

### 3.2 功能详细说明

---

#### F-01 创建任务

**描述**：用户通过表单创建新任务。

**字段说明**：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| 标题 | 文本 | ✅ | — | 1~100 个字符 |
| 描述 | 长文本 | ❌ | 空 | 最多 1000 个字符 |
| 分类 | 下拉选择 | ❌ | "默认" | 从已有分类中选择 |
| 优先级 | 单选 | ❌ | 中 | 低 / 中 / 高 |
| 截止日期 | 日期选择器 | ❌ | — | 不早于今天 |

**业务规则**：
- 标题不能为空且不能超过 100 字符
- 截止日期不能选择过去的日期
- 创建成功后，任务状态默认为"待办"
- 创建成功后表单自动清空，显示成功提示

**验收标准**：
1. 填写标题后点击"创建"，任务出现在列表中
2. 标题为空时，显示红色错误提示，无法提交
3. 选择过去的日期时，显示错误提示

---

#### F-02 查看任务列表

**描述**：以列表形式展示所有任务，支持筛选与排序。

**功能细节**：

| 功能 | 说明 |
|------|------|
| 默认视图 | 显示所有未完成任务，按创建时间倒序排列 |
| 状态筛选 | 可按"全部 / 待办 / 进行中 / 已完成"筛选 |
| 分类筛选 | 可按分类名称筛选 |
| 优先级排序 | 支持按优先级 高→低 排序 |
| 搜索 | 支持按任务标题关键词搜索 |

**列表项展示信息**：
- 任务标题
- 状态标签（彩色徽章）
- 优先级指示（颜色/图标）
- 分类名称
- 截止日期（过期任务红色高亮）
- 快捷操作按钮（编辑、删除、状态切换）

**验收标准**：
1. 页面加载后 1 秒内显示任务列表
2. 切换筛选条件后列表即时更新
3. 无任务时显示空状态插图和引导文案
4. 过期任务的截止日期显示为红色

---

#### F-03 编辑任务

**描述**：用户可修改任务的任意属性。

**业务规则**：
- 点击编辑按钮后弹出编辑表单（模态框或侧边抽屉）
- 表单预填当前任务的所有信息
- 编辑表单的字段规则与创建表单一致
- 修改后点击"保存"立即生效，列表同步更新

**验收标准**：
1. 编辑表单正确预填所有现有数据
2. 保存后列表立即反映变更
3. 取消编辑不保存任何更改

---

#### F-04 删除任务

**描述**：用户可删除不需要的任务。

**业务规则**：
- 点击删除按钮后弹出二次确认对话框
- 确认后任务从数据库和列表中移除
- 删除后显示"已删除"提示（支持撤销操作，可选）

**验收标准**：
1. 点击删除后弹出确认框，不直接删除
2. 确认后任务消失，列表刷新
3. 删除后显示成功提示

---

#### F-05 任务状态流转

**描述**：任务在生命周期中经历不同状态。

**状态定义**：

| 状态 | 颜色标识 | 说明 |
|------|----------|------|
| 待办 (TODO) | 🔵 蓝色 | 新创建或重新打开的任务 |
| 进行中 (IN_PROGRESS) | 🟡 黄色 | 正在处理的任务 |
| 已完成 (DONE) | 🟢 绿色 | 已完成的任务 |

**流转规则**：

```
待办 ──→ 进行中 ──→ 已完成
 │                      │
 └──────────────────────┘
       (可回退到任意状态)
```

- 任意状态之间可以自由切换（双向流转）
- 状态切换通过列表中的快捷按钮一键操作
- 状态变更立即生效，无需额外确认

**验收标准**：
1. 点击状态按钮可循环切换：待办 → 进行中 → 已完成
2. 也支持通过编辑表单修改状态
3. 状态变更后列表中的标签颜色立即更新

---

#### F-06 任务分类管理

**描述**：用户可自定义任务分类。

**预置分类**：工作、学习、生活、默认

**功能细节**：
- 查看分类列表（侧边栏或设置页）
- 新增分类（输入分类名称，1~20 字符）
- 编辑分类名称
- 删除分类（该分类下的任务自动归入"默认"分类）

**业务规则**：
- 分类名称不可重复
- 预置分类不可删除（但可编辑名称）
- 删除分类时弹出提示："该分类下的 N 个任务将移至'默认'分类"

**验收标准**：
1. 新增分类后立即出现在分类列表中
2. 创建任务时可选择新建的分类
3. 删除分类后，原分类任务变为"默认"分类

---

#### F-07 优先级设置

**描述**：每个任务可设置低、中、高三个优先级。

| 优先级 | 颜色标识 | 含义 |
|--------|----------|------|
| 高 (HIGH) | 🔴 红色 | 紧急重要，需优先处理 |
| 中 (MEDIUM) | 🟠 橙色 | 一般任务，正常排期 |
| 低 (LOW) | 🟢 绿色 | 不紧急，空闲时处理 |

**验收标准**：
1. 任务列表中通过颜色/图标直观区分优先级
2. 支持按优先级排序

---

#### F-08 截止日期提醒（视觉提示）

**描述**：通过视觉方式提示用户任务的截止日期状态。

> v1.0 采用 **视觉提醒**（不做弹窗/邮件/推送通知），降低实现复杂度。

**提醒规则**：

| 条件 | 视觉表现 |
|------|----------|
| 截止日期 > 7 天 | 正常显示截止日期 |
| 截止日期 ≤ 7 天 | 截止日期文字变为橙色 |
| 截止日期已过期 且 任务未完成 | 截止日期文字变为红色 + 显示"已过期"标签 |
| 任务已完成 | 不显示过期提示 |

**验收标准**：
1. 即将过期的任务有明显的颜色区分
2. 过期任务有醒目的红色标记
3. 已完成任务不显示过期警告

---

#### F-09 统计面板

**描述**：以可视化方式展示任务完成情况。

**统计指标**：

| 指标 | 说明 |
|------|------|
| 任务总数 | 所有任务的数量 |
| 各状态数量 | 待办 / 进行中 / 已完成的数量 |
| 完成率 | 已完成数 / 总数 × 100% |
| 今日完成数 | 今天标记为完成的任务数 |
| 逾期任务数 | 截止日期已过但未完成的任务数 |
| 各分类任务数 | 按分类统计任务数量 |

**可视化方式**：
- 状态分布：环形图或进度条
- 分类分布：柱状图或饼图
- 趋势：近 7 天每日完成数量折线图（可选，作为增强功能）

**验收标准**：
1. 数据面板实时反映最新统计（每次进入页面重新计算）
2. 图表清晰易读，有图例说明
3. 无任务时显示"暂无数据"提示

## 5. 数据模型设计

### 5.1 数据库选型

使用 **SQLite**，理由：
- 零配置，无需安装数据库服务
- 数据以文件形式存储，便于开发和调试
- 支持标准 SQL，学习成本低

### 5.2 ER 关系图

```
┌──────────────┐       ┌──────────────────┐
│  categories  │ 1   N │      tasks       │
├──────────────┤       ├──────────────────┤
│ id (PK)      │───────│ id (PK)          │
│ name         │       │ title            │
│ is_builtin   │       │ description      │
│ created_at   │       │ status           │
└──────────────┘       │ priority         │
                       │ category_id (FK) │
                       │ due_date         │
                       │ created_at       │
                       │ updated_at       │
                       └──────────────────┘
```

### 5.3 表结构详细设计

#### categories 表（分类表）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 分类唯一标识 |
| `name` | VARCHAR(20) | NOT NULL UNIQUE | 分类名称 |
| `is_builtin` | INTEGER | NOT NULL DEFAULT 0 | 是否为预置分类（1=是，0=否） |
| `created_at` | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**预置数据**：

```sql
INSERT INTO categories (name, is_builtin) VALUES
  ('默认', 1),
  ('工作', 1),
  ('学习', 1),
  ('生活', 1);
```

#### tasks 表（任务表）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 任务唯一标识 |
| `title` | VARCHAR(100) | NOT NULL | 任务标题 |
| `description` | TEXT | DEFAULT '' | 任务描述 |
| `status` | VARCHAR(20) | NOT NULL DEFAULT 'TODO' | 状态：TODO / IN_PROGRESS / DONE |
| `priority` | VARCHAR(10) | NOT NULL DEFAULT 'MEDIUM' | 优先级：LOW / MEDIUM / HIGH |
| `category_id` | INTEGER | DEFAULT 1 | 外键，关联 categories.id |
| `due_date` | DATE | | 截止日期（可为空） |
| `created_at` | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 最后更新时间 |

**约束**：

```sql
-- 状态值约束
CHECK (status IN ('TODO', 'IN_PROGRESS', 'DONE'))
-- 优先级值约束
CHECK (priority IN ('LOW', 'MEDIUM', 'HIGH'))
-- 外键约束
FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET DEFAULT
```

### 5.4 建表 SQL

```sql
-- 分类表
CREATE TABLE IF NOT EXISTS categories (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  name       VARCHAR(20) NOT NULL UNIQUE,
  is_builtin INTEGER NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 任务表
CREATE TABLE IF NOT EXISTS tasks (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  title       VARCHAR(100) NOT NULL,
  description TEXT DEFAULT '',
  status      VARCHAR(20) NOT NULL DEFAULT 'TODO'
                CHECK (status IN ('TODO', 'IN_PROGRESS', 'DONE')),
  priority    VARCHAR(10) NOT NULL DEFAULT 'MEDIUM'
                CHECK (priority IN ('LOW', 'MEDIUM', 'HIGH')),
  category_id INTEGER DEFAULT 1,
  due_date    DATE,
  created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET DEFAULT
);

-- 预置分类
INSERT INTO categories (name, is_builtin) VALUES
  ('默认', 1), ('工作', 1), ('学习', 1), ('生活', 1);
```


### 6.3 核心交互规范

| 交互 | 规范 |
|------|------|
| 反馈 | 所有操作（创建/编辑/删除/状态变更）完成后显示 Toast 提示 |
| 加载 | API 请求期间对应按钮显示 Loading 状态，禁止重复提交 |
| 空状态 | 列表为空时显示插图 + 引导文案（如"还没有任务，创建一个吧！"） |
| 确认 | 删除操作必须二次确认；其他操作即时生效 |
| 表单校验 | 实时校验 + 提交校验，错误信息直接显示在字段下方 |
| 键盘支持 | 支持 Tab 切换表单字段，Enter 提交表单，Esc 关闭模态框 |

## 7. API 接口设计

### 7.1 接口总览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/tasks` | 获取任务列表（支持筛选、排序、搜索） |
| POST | `/api/tasks` | 创建任务 |
| GET | `/api/tasks/:id` | 获取单个任务详情 |
| PUT | `/api/tasks/:id` | 更新任务 |
| PATCH | `/api/tasks/:id/status` | 快速切换任务状态 |
| DELETE | `/api/tasks/:id` | 删除任务 |
| GET | `/api/categories` | 获取分类列表 |
| POST | `/api/categories` | 创建分类 |
| PUT | `/api/categories/:id` | 更新分类 |
| DELETE | `/api/categories/:id` | 删除分类 |
| GET | `/api/stats` | 获取统计数据 |

### 7.2 统一响应格式

**成功响应**：

```json
{
  "success": true,
  "data": { ... }
}
```

**列表响应**（含分页，v1.0 暂不分页，返回全量）：

```json
{
  "success": true,
  "data": [ ... ],
  "total": 24
}
```

**错误响应**：

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "任务标题不能为空"
  }
}
```

### 7.3 查询参数说明

`GET /api/tasks` 支持的查询参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `status` | string | 筛选状态：TODO / IN_PROGRESS / DONE |
| `category_id` | number | 筛选分类 |
| `priority` | string | 筛选优先级：LOW / MEDIUM / HIGH |
| `keyword` | string | 按标题关键词搜索 |
| `sort_by` | string | 排序字段：created_at / priority / due_date |
| `sort_order` | string | 排序方向：asc / desc（默认 desc） |
