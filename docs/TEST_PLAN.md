## 1. 测试概述

### 1.1 测试目标

| 目标 | 说明 |
|------|------|
| **功能正确性** | 验证所有功能需求（F-01 ~ F-09）按 PRD 描述正确运行 |
| **数据一致性** | 确保前后端数据流转准确，数据库状态与 UI 展示一致 |
| **边界健壮性** | 验证异常输入、极端场景下系统不崩溃并给出合理反馈 |
| **用户体验** | 确保交互流畅、反馈及时、错误提示友好 |
| **性能基线** | 满足 PRD 定义的性能指标（页面加载 ≤2s，API ≤200ms） |

### 1.2 测试范围

| 范围 | 包含 | 不包含 |
|------|------|--------|
| **功能测试** | 任务 CRUD、分类管理、状态流转、筛选排序搜索、统计面板 | 用户认证/登录（v1.0 不涉及） |
| **接口测试** | 全部 11 个 RESTful API 端点 | 第三方服务集成（无） |
| **UI 测试** | 布局、组件渲染、交互反馈、响应式 | 浏览器兼容性全覆盖（仅测 Chrome 最新版） |
| **性能测试** | 页面加载、API 响应、列表渲染 | 压力测试、并发测试（个人工具无需） |
| **安全测试** | SQL 注入、XSS、输入校验 | 渗透测试、认证授权（v1.0 不涉及） |

### 1.3 测试工具

| 工具 | 用途 | 测试层级 |
|------|------|----------|
| **Vitest** | 后端 Service 层单元测试 | 单元测试 |
| **Supertest** | API 接口集成测试（可选） | 集成测试 |
| **浏览器 DevTools** | 前端功能验证、网络请求检查 | 功能测试 |
| **手动测试** | 端到端场景验证、UI 交互验证 | E2E 测试 |
| **Lighthouse** | 性能审计、最佳实践检查 | 非功能测试 |

## 2. 测试策略与分层

### 2.1 测试金字塔

```
              ╱╲
             ╱  ╲          手动 E2E 测试（5%）
            ╱ E2E╲         完整业务流程验证
           ╱──────╲
          ╱        ╲       API 接口测试（15%）
         ╱  集成测试 ╲     各端点请求/响应验证
        ╱────────────╲
       ╱              ╱    单元测试（30%）
      ╱   单元测试    ╱    Service 层 + 工具函数
     ╱──────────────╱
    ╱                ╲    手动功能测试（50%）
   ╱   手动功能验证    ╲   前端交互、UI 渲染、用户体验
  ╱────────────────────╲
```

### 2.2 测试优先级矩阵

| 优先级 | 测试内容 | 方式 | 执行时机 |
|--------|----------|------|----------|
| **P0 阻塞级** | 任务 CRUD 完整流程 | 手动 E2E | 每次功能开发完成后 |
| **P0 阻塞级** | 分类管理完整流程 | 手动 E2E | 每次功能开发完成后 |
| **P0 阻塞级** | API 参数校验与错误处理 | 接口测试 | 后端开发完成后 |
| **P1 重要** | 筛选/排序/搜索正确性 | 手动功能 | 联调完成后 |
| **P1 重要** | 状态流转正确性 | 手动功能 | 联调完成后 |
| **P1 重要** | 统计数据准确性 | 手动 + 单元测试 | 统计功能完成后 |
| **P2 建议** | Service 层边界场景 | 单元测试 | 后端开发完成后 |
| **P2 建议** | 工具函数正确性 | 单元测试 | 开发完成后 |
| **P3 可选** | 响应式布局验证 | 手动 UI 测试 | 优化阶段 |
| **P3 可选** | 性能基线检测 | Lighthouse | 交付前 |

### 2.3 测试阶段安排

```
Day 1-2 后端开发 ──→ 后端单元测试 + API 接口测试
Day 3   前端开发 ──→ 前端组件渲染手动验证
Day 4   联调阶段 ──→ 端到端场景测试（核心流程）
Day 5   优化阶段 ──→ 边界测试 + 回归测试 + 性能测试
```

## 11. 缺陷管理

### 11.1 缺陷严重等级

| 等级 | 定义 | 示例 | 修复时限 |
|------|------|------|----------|
| **S1 阻塞** | 核心功能不可用，系统崩溃 | 创建任务报错、页面白屏、数据库异常 | 立即修复 |
| **S2 严重** | 核心功能异常但有变通方案 | 状态切换后列表不刷新、筛选结果错误 | 当天修复 |
| **S3 一般** | 非核心功能异常或体验问题 | Toast 不显示、排序不生效、样式错位 | 当前迭代修复 |
| **S4 建议** | 优化建议，不影响使用 | 动画不够流畅、文案不够友好 | 下个迭代考虑 |
