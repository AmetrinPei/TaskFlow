## 4. 请求链路知识图谱

### 4.1 创建任务的完整链路

```
用户操作                   前端                         后端                      数据库
──────────────────────────────────────────────────────────────────────────────────────
填写表单
点击"创建"
    │
    ▼
TaskForm.tsx
    │ 校验标题非空
    │ 收集表单数据
    │
    ▼
useTasks.createTask()
    │ setLoading(true)
    │
    ▼
taskApi.create(data)
    │
    ▼
apiClient.post('/tasks', data)
    │                           │
    │  POST /api/tasks          │
    │  Content-Type: JSON       │
    │  Body: {title, ...}       │
    │──────────────────────────→│
    │                           │
    │                     app.ts 中间件
    │                     ├── cors()
    │                     └── express.json()
    │                           │
    │                     taskRoutes.ts
    │                     ├── validate(createTaskSchema)
    │                     │   └── zod.safeParse(body)
    │                     │       ├── 失败 → 400 返回
    │                     │       └── 成功 → next()
    │                     │
    │                     taskController.create
    │                     ├── try {
    │                     │     taskService.create(data)
    │                     │         │
    │                     │         │  db.prepare('INSERT INTO tasks...')
    │                     │         │  .run(title, desc, priority, ...)
    │                     │         │──────────────────────────→ INSERT
    │                     │         │
    │                     │         │  this.getById(lastId)
    │                     │         │──────────────────────────→ SELECT (含 JOIN)
    │                     │         │←────────────────────────── 返回完整任务
    │                     │         │
    │                     │     successResponse(task)
    │                     │   } catch(e) { next(e) }
    │                           │
    │  201 Created              │
    │  {success:true,data:{...}}│
    │←──────────────────────────│
    │
apiClient 拦截器
    └── 解包 response.data
    │
useTasks
    ├── setTasks(prev => [newTask, ...prev])
    ├── setLoading(false)
    └── addToast('创建成功')
    │
    ▼
React 重新渲染
    └── TaskList 显示新任务
```

### 4.2 获取任务列表的链路

```
页面加载
    │
    ▼
useTasks.fetchTasks(filters)
    │
    ▼
taskApi.getAll(params)
    │
    ▼
GET /api/tasks?status=TODO&sort_by=created_at
    │
    ▼
taskRoutes → validate(querySchema) → taskController.getAll
    │
    ▼
taskService.getAll(params)
    │
    ├── 构建动态 WHERE 条件
    │   ├── status = ? → 'TODO'
    │   └── (无其他筛选)
    │
    ├── 构建 ORDER BY
    │   └── t.created_at desc
    │
    ├── 执行 SQL
    │   SELECT t.*, c.name AS category_name
    │   FROM tasks t LEFT JOIN categories c ON t.category_id = c.id
    │   WHERE t.status = 'TODO'
    │   ORDER BY t.created_at DESC
    │
    └── 返回 Task[]
    │
    ▼
successResponse(tasks) → 200 → 前端 → setTasks → 渲染列表
```
